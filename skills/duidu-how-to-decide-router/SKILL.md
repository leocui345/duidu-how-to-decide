# 对赌（实践版） — 来源路由入口（compact pack）

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。  
**不适用**：

- 投融资对赌协议（VAM／估值调整机制）的条款、估值与法律含义
- 赌博、赌球、押注策略
- 股票/基金推荐与投资建议
- 法律、医疗、税务的专业意见

- 《Thinking in Bets》内容

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 决策质量与结果质量是两个独立变量，中间夹着运气——用结果反推决策会同时破坏学习与同情心
2. 概率必须被外化（写下来、给范围），否则"很可能"在沟通中等于没说话
3. 你的内视角永远不可信；准确性存在于内视角与外视角的交集处
4. 速度是决策质量的一部分——按"决策不正确的代价"分配思考时间，不是越多越好
5. 失败通常来自"单独看都合理的累积"，而非某个明显的错误决策
6. 目标是长期决策组合的整体前进，不是单次全中
7. 先判"这是哪一类问题"，再按路由表加载 1 张能力卡；跨域时最多 2 张
8. 概览类问题（"这本书讲了什么"）用核心原则与 overview 回答，不加载能力卡
9. 复盘类问题按 结果导向 → 后视偏差 → 多重可能性 的顺序走完三步
10. 处理"将要做的决策"时，在回复末尾附一份可复制的【决策留档】模板（决策前已知 / 决策 / 结果待填）， 只输出文本供用户自行保存，**不主动写入任何文件**——这是书里"给后视偏差打疫苗"的核心机制

## 加载规则

- 每次任务先读本文件，再按路由表加载 **1** 张能力卡；任务明确跨域时最多加载 2 张。
- 概览/书名类问题不加载能力卡，用「核心原则」与 overview.md 回答。
- 路由表与 capability-index.md 都无法命中的意图，明确告知超出本书范围，不要硬套。

## 边界与判停

- 用户要求替他做实质决定（"你就说我该选哪个"）→ 只把工具拆成问题清单，让他自己填
- 出现不可逆、大额、涉及健康/法律/他人重大利益的决策 → 加一行风险提示并建议咨询专业人士
- 卡片与索引均无法命中意图 → 明确告知超出本书范围，不要硬套
- 路由表与能力索引都命不中 → 明确告知超出本书范围
- 用户要求替他下结论 → 只给问题清单
- 高风险不可逆决策 → 加风险提示 + 建议专业人员
