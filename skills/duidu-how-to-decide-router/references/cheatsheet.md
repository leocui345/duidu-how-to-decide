# 决策规则速查 — 对赌（实践版）

| 能力 | 一句话规则 |
|---|---|
| 六步决策法 | 把直觉转成可比较数字——穷举结果、标回报大小、标概率、换算成同一单位再比较 |
| 事前验尸与倒推 | 假想它已经失败了，回过头找原因——分可控/不可控各列 5 条，标概率，再定动作 |
| 决策速度分诊 | 按"决策不正确的代价"分配时间——代价小就快；难选恰恰说明可以随便选 |
| 概率外化与校准 | 把"大概率"换成百分比，再给范围并做震惊测验——目标是十发九中 |
| 决策卫生 | 隔离观点、隔离结果、中立提问；团队先单独、后匿名、再讨论 |
| 非对称性决策（但试无妨与累积陷阱） | 先问不对称性（输了会比我现状更差吗），再问累积性（这事我会做几次） |
| 主动放弃与退出成本 | 退出成本越低，决策就可以越快；先剥离沉没成本，再问"今天第一次面对它，你会选吗" |
| 结果导向与决策质量矩阵 | 把成败拆成决策质量与结果质量两个正交轴，四象限定位 |
| 后视偏差与知识跟踪 | 记忆没有时间戳——把"决策前已知"与"结果后才知"分开记录 |
| 多重可能性与重建决策树 | 把被"认知链锯"砍掉的其他可能性粘回树上，给实际结果称重 |
| 外视角与基准数 | 先写外视角（世界的真实情况＋别人怎么看），再写内视角，最后找交集 |
| 披着狼皮的羊 | 难选不等于重要——问"如果随便选，我会错到什么程度" |
| 预先承诺与分类决策 | 不靠意志力靠结构——根本防止、设障碍、减障碍，最高形式是把整类选项划掉 |
| 上头与情绪化决策 | 坏结果会抑制理性脑区——先中断一个睡眠周期，再做不可逆动作 |
| 对冲 | 三特征检验——能减少坏运气影响、有成本、你希望它永远用不上 |
| 决策组合观 | 把一生决策看成一个投资组合——目标是整体前进，不是单次全中 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
