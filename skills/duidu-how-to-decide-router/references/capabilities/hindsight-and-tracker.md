# 后视偏差与知识跟踪

## R — Reading（原文）

> 后视偏差把"水晶球"变成了"哈哈镜"。……我们的记忆没有时间戳。
>
> —— 第二章 037

> 写下影响决策的关键事实，就像提前给后视偏差"打疫苗"。
>
> —— 第二章 041

## I — Interpretation（自述）

后视偏差＝事后认为结果**可预测或不可避免**的倾向。它有两种歪曲方式：**"早就知道"**（篡改对当时想法的记忆）和**"本该知道"**（认为当时就该预见）。它还有一个帮凶叫**记忆偏差**——事后信息会悄悄污染你对事前记忆的存档。

作者的关键洞察是：**记忆没有时间戳**。你无法靠"好好回忆"来对抗它，只能靠**在决策当时就写下来**。

**知识跟踪器**是具体解法：

```
做决策前就知道的事  →  决策  →  结果  →  结果出来后才知道的事
```

左栏＝你做决策时掌握的知识与信念；右栏＝决策前掌握的一切 ＋ 决策后才了解的新信息。左栏**必须在决策当时记录**，否则会被右栏污染。

## A1 — Past Application（书中案例）

**波士顿工作（第二章 039）**
情形 A（六个月后辞职）：左栏＝波士顿气温/冬季时长/降雪量、工作机会详情、2 月逗留经历；右栏＝在波士顿过了几个月冬天的经历、你喜欢这份工作的程度、你辞职并搬回老家。
情形 B（留下并爱上冬天）：左栏完全相同，右栏变为＝几个月冬天的经历、你热爱滑雪且滑得很棒、你长期留在了波士顿。
**要点：两套情境的左栏一字不差——决策没变，只是结果不同。**

**2016 年美国大选（第二章 047–049）**：作者在搜索页向后翻了 **10 页**，**找不到任何一篇**大选前批评希拉里忽视密歇根/宾州/威斯康星的文章；相反，选前仅有的相关评论是**批评特朗普**去这些州纯属浪费时间。而选前民调在这三州显示希拉里领先数个百分点。

## A2 — Future Trigger（何时触发）★

**适用情境**：
1. 听到"我早说过/我就知道/我早该知道"；
2. 复盘旧决策（含评价他人当时的选择）；
3. **【前摄用法】用户正在描述一个"将要做的"重要决策**——此时应**主动提议**为它生成一份可复制的留档模板（这是书里"给后视偏差打疫苗"的核心机制：只在决策当时记录才有效，事后补填等于用被污染的记忆填写）；
4. 用户问"怎么才能不被结果影响判断""怎么在决策当时留个记录"。

**语言信号（中/英）**：
"我早就知道会这样 / 我早说过 / 我当时就预感到了 / 我准备做这个决定，想留个记录"
"I knew it / told you so / I'm about to decide, want a record / hindsight bias"

**与相邻能力的区分**：本能力管**记忆的准确性**；结果导向（U01）管**评价的公正性**；多重可能性（U03）管**可能性的完整性**。听到"我早该知道"→ 本能力；听到"当初这个决定做错了"→ U01。

> **前摄触发提示**：当 `six-step-decision` 或 `premortem-backcast` 正在处理一个"将要执行"的决策时，若用户未提出记录需求，本能力**不主动抢触发**；但 router 在处理前瞻类请求时，应在回复末尾附上留档模板。

## E — Execution（可执行步骤）

1. **抓语言信号**：指出原句中的"我早说过/我就知道/我本该知道"。
   完成标准：原句被复述。
2. **处理四问**：① 你是否在**事后**获知了一些信息？② 这些信息在**做决策时是否合理可知**？③ 结论是否基于当时不可能知道的信息？④ 重新评估结果的可预测性。
   完成标准：四问都得到回答。
3. **填知识跟踪表**：左栏写"决策当时确实知道的 3 件事"，右栏写"结果出来后才知道的 3 件事"。
   完成标准：左栏内容不含任何事后信息（若含，标出并剔除）。
4. **留档建议**：对未来的重要决策，建议当场记录左栏。
   完成标准：用户得到一个可复制的记录模板。

**判停点**：若用户拿不出任何"当时就知道什么"的记录 → 明确说明"无法事后重建，本次不宜下结论"，只做语言信号提示。

## B — Boundary（边界）

**不要使用**：结果尚未产生时；纯粹的情绪安慰场景。

**书中警告的失败模式**：拿"结果出来后才知道的事"去质问当事人"你为什么没想到"——"如果有什么会比一辈子都在后悔'早该知道'更糟，那就是一边后悔一边还要听别人对你说'我早说过'。"（二 033）

**作者局限带来的边界**：知识跟踪器**只在决策当时记录才有效**。事后补填等于用被污染的记忆填写，会让工具失效。因此本能力的现实价值主要在"建立习惯"，而非"拯救旧决策"。

**易混淆的相邻方法**：结果导向（评价）、记忆偏差（机制）、认知链锯（多重可能性）。
