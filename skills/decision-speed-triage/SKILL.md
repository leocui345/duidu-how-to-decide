# 决策速度分诊

## R — Reading（原文）

> 我们都会面临很多类似去欧洲哪里度假的高影响力决策。……让我们做一个怪怪的思想小实验：假如你不是在巴黎和罗马之间做选择，而是在巴黎和三文鱼罐头厂之间做选择呢？你会感觉困难或焦虑吗？我想答案是否定的。这表明相似选项才是拖慢决策速度的原因。
>
> —— 第七章 187

> 难以决策的时候其实很容易选择。
>
> —— 第七章 189（侧栏）

## I — Interpretation（自述）

这本书里最反直觉的一个命题是：**"难选"不是"该慢慢想"的信号，而是"可以随便选"的信号。** 因为难选恰恰说明两个选项的品质非常接近——无论选哪个都不会错。你之所以难受，不是因为风险大，而是因为你在追求一种**并不存在的确定性**。

分诊的判据只有一条：**决策不正确的代价有多大？** 代价小 → 快；代价大 → 慢。作者给出五个"代价小"的识别器：

1. **幸福感测验**——结果一年内会显著影响我的幸福感吗？答"不"就通过；
2. **重复性选择**——同类决策会出现第二次（选电影、选路线），可以回头补选；
3. **但试无妨**——下行有限、上行可观；
4. **相近选项**——问"如果随便选，我会错到什么程度"；
5. **退出成本低**——将来改主意要付多少代价。

命中任意一条，就在该维度上加速。作者同时给出一个有用的口径：**多花时间在"分类"上（搞清自己喜欢什么），少花时间在"选择"上**——这叫菜单策略。

## A1 — Past Application（书中案例）

**每年 250~275 小时（第七章 171/172）**
遇到问题：作者给出统计——每人每年平均花在决定"吃什么（150 分钟/周）、看什么（50 分钟/周）、穿什么（90~115 分钟/周）"上的时间合计达 250~275 小时，约 6~7 个工作周。
怎么用：用幸福感测验检验这三类决策——一年后你会记得那顿饭吗？不会。
结论：这三类全部通过测验，可大幅加速，把时间挪给有影响力的决策。

**巴黎 vs 罗马（第七章 186–190）**
遇到问题：一周假期去巴黎还是罗马，用户打分"极为困难"。
怎么用：① 幸福感测验——不通过（会影响一年）；② 不是重复性选择；③ 换成"巴黎 vs 三文鱼罐头厂"立刻不难了 → 说明成因是"选项相近"；④ 用唯一选择测验："如果只能去巴黎，我会满意吗？"→ 会；"只能去罗马呢？"→ 也会。
结论：**随机选择即可**。作者进一步算账：若完全信息下巴黎 +4.9%、罗马 +5.1%，你花的大量时间只为找出 **0.2%** 的差别。

## A2 — Future Trigger（何时触发）★

**适用情境（3–5 条）**：
1. 用户为**小事**反复纠结或频繁改主意；
2. 用户说"这两个我实在选不出来"（选项品质接近）；
3. 用户问"这件事我需要花多少时间考虑"；
4. 用户陷入"分析瘫痪"，迟迟不拍板；
5. 用户在为"要不要继续纠结"而内耗。

**语言信号（中/英）**：
"这件小事我居然纠结了半天 / 两个都差不多选不出来 / 我得花多少时间想这事儿 / 我就是拍不了板 / 选择困难"
"can't decide / they're basically the same / how much time should I spend on this / analysis paralysis / decision fatigue"

**与相邻能力的区分**：
- 与 **六步决策法**：本能力先跑，判"值不值得用六步法"。命中释放条件 → 直接用本能力快速决定，不要再上重武器。
- 与路由入口内的 **披着狼皮的羊**：本能力给出"是否该加速"的**判断框架**；披着狼皮的羊是其中"相近选项"这一支的深化操作（唯一选择测验、菜单策略）。一句"帮我判判这事值不值得纠结"落在本能力。
- 与 **主动放弃**：本能力管"开始前的速度"；主动放弃管"回头的成本"。若用户问"将来改主意麻烦吗"，可在本能力第 5 条释放后转入主动放弃卡。

## E — Execution（可执行步骤）

1. **跑幸福感测验**：问"这个结果一年内会显著影响你的幸福感吗？一个月呢？一周呢？"
   完成标准：得到明确的时间尺度答案。
2. **查是否为重复性选择**：问"类似的决策以后还会出现吗？还会出现几次？"
   完成标准：能说清"下次什么时候还能再选一次"。
3. **查是否但试无妨**：问"最糟的结果是什么？""结果不好时，你会比现在更差吗？"
   完成标准：能判定下行是否有限。
4. **查选项是否相近**：问"如果随便选，你会错到什么程度？"＋做唯一选择测验（对每个选项问"如果这是唯一的选择，我会感觉满意吗？"）。
   完成标准：至少两个选项的答案都是"满意"。
5. **查退出成本**：问"如果选错了，多久能改？改的代价是什么？"
   完成标准：能给出一个具体的"放弃代价"。
6. **给出加速结论与释放方式**：命中任一 → 明确说"这个可以快"，并给出加速方式（抛硬币 / 菜单策略 / 直接挑一个）。
   完成标准：用户得到一个**可执行的"快"的动作**，而不是"你可以放松点"这类安慰。

**判停点**：
- 五条**全部不命中** → 停止加速，转入六步决策法或事前验尸。
- 第 3 步发现"最糟结果不可逆或影响极大" → 停止，转主动放弃或事前验尸。
- 用户情绪明显焦虑（而非只是拖延）→ 先处理焦虑，不要用分诊结论压他。

## B — Boundary（边界）

**不要使用的场景**：
- 不可逆、大额、涉及他人重大利益或人身安全的决策——这些恰恰**必须慢**；
- 用户已经进入深度分析并接近结论时，不要打断他"这个其实可以快"；
- 用户的真实困惑是"我不知道自己想要什么"——那是偏好问题，不是速度问题（走菜单策略/分类）。

**书中警告的失败模式**：
- **把"难选"误读为"重要"**：这是本能力要纠正的头号错误；
- **为相近选项做无用功**——"你花了那么多时间，只是在追求一种虚幻的确定性"（第七章 190）；
- **在本该快的决策上追求最优**——"最高决策者的倾向是花费大量时间追求确定性"（第七章 210）。

**作者局限带来的边界**：
- **假定有慢下来的自由**（阶段 0 批判）：一线员工、照护者在高压下可能**连跑分诊的时间都没有**。此时应给"默认动作"（如"直接选第一个"），而不是要求他先评估五条。
- **"快"的代价不可见**：加速省下的时间若没有明确的去处，用户会感到"我是不是草率了"。建议在第 6 步明确说"省下的时间可以拿去做什么"。

**易混淆的相邻方法**：六步决策法（慢工具）、满意决策（心态而非流程）、菜单策略（加速的具体技法之一）。
